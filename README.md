🗓️ Monthly Habit Tracker

A modern and interactive Monthly Habit Tracker built with HTML, CSS, and JavaScript. Track your habits, sleep, finances, and personal notes in one place with automatic data saving and beautiful visual analytics.

📸 Overview

The Monthly Habit Tracker helps you:

✅ Build positive habits
😴 Monitor sleep patterns
💰 Manage personal finances
📝 Record notes and reflections
📊 Visualize progress through charts
🌙 Switch between Light and Dark Mode

All data is stored locally in your browser, ensuring privacy and quick access.
